# Fil for Mac

Downloads and updates for [Fil](https://fil.design)'s Mac app.

**[Download Fil for Mac](https://fil.design/download)**, or get the newest
`Fil.dmg` under [Releases](https://github.com/MengTo/fil-releases/releases/latest).
It runs on macOS 12 or later, on Apple Silicon and Intel Macs, and keeps
itself up to date from the releases here.

This repository holds only the signed, notarized releases; there's no code
in it.
